# README.md

## Проект: Система аутентификации пользователей

Это веб-приложение, реализующее систему регистрации и аутентификации пользователей с использованием Flask, SQLAlchemy и Flask-Login. Приложение позволяет пользователям регистрироваться, входить в систему, обновлять свои профили и выходить из системы.

### Установка

#### Требования

- Python 3.6 или выше
- Flask
- Flask-SQLAlchemy
- Flask-Login
- Flask-WTF
- Werkzeug (для хеширования паролей)

#### Установка зависимостей

1. Клонируйте репозиторий:

   ```bash
   git clone <URL_репозитория>
   cd <имя_папки_репозитория>
   ```

2. Создайте виртуальное окружение:

   ```bash
   python -m venv venv
   source venv/bin/activate  # для Linux/Mac
   venv\Scripts\activate  # для Windows
   ```

3. Установите необходимые пакеты:

   ```bash
   pip install -r requirements.txt
   ```

### Настройка

1. Создайте файл конфигурации `config.py` и добавьте следующие параметры:

   ```python
   import os

   class Config:
       SECRET_KEY = os.environ.get('SECRET_KEY') or 'ваш_секретный_ключ'
       SQLALCHEMY_DATABASE_URI = os.environ.get('DATABASE_URL') or 'sqlite:///site.db'
       SQLALCHEMY_TRACK_MODIFICATIONS = False
   ```

2. Убедитесь, что у вас установлен SQLite, или настройте подключение к другой базе данных.

### Запуск приложения

1. Создайте базы данных (раскомментируйте строку в конце вашего кода):

   ```python
   db.create_all()
   ```

2. Запустите приложение:

   ```bash
   python app.py
   ```

3. Перейдите по адресу `http://127.0.0.1:5000/` в вашем веб-браузере.

### Использование

- **Регистрация**: Перейдите по адресу `/register`, чтобы создать новый аккаунт.
- **Вход**: Перейдите по адресу `/login`, чтобы войти в систему.
- **Профиль**: После входа в систему вы сможете обновлять свои данные в разделе `/profile`.
- **Выход**: Для выхода из системы перейдите по адресу `/logout`.
